# Lightning Roulette Tracker

Вебтрекер ручного введення чисел 0–36, пошуку патернів і надсилання сигналів у Telegram.

## Запуск
Потрібен Node.js 18+. Виконайте `npm install`, задайте `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID`, потім `npm start` та відкрийте `http://localhost:3000`. Для локального `.env` використайте Node 20.6+: `node --env-file=.env server.js`.

## GitHub + Railway
Завантажте всі файли в GitHub. У Railway створіть Deploy from GitHub repo, додайте Variables `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID`. Додайте бота адміністратором каналу з правом публікації. GitHub Pages не запускає Node-сервер, тому застосунок потрібно розгорнути на Railway. Токен не додавайте в GitHub.

## Логіка
Патерн шукається у послідовності М/В (Мале 1–18, Велике 19–36; 0 розриває послідовність). Ставка перевіряється на наступних 9 введених числах. WIN — категорія зустрілася хоча б раз; LOSS — не зустрілася. Нуль не належить до жодної ставки. Дані браузера зберігаються в localStorage. Історичні сигнали та LOSS відображаються як довідкові; WIN не виводиться, бо його не було в початкових даних. Це статистичний інструмент, не прогноз і не гарантія.
